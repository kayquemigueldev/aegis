# Indicadores de sucesso

Roadmap: AEGIS-011

| Indicador | Método | Situação |
|---|---|---|
| Integridade da ingestão | Comparar entrada e relatório | A validar |
| Taxa de processamento | Eventos/segundo em benchmark | Sem baseline |
| Latência | Média, p95, p99 | Sem baseline |
| Consumo de memória | Profiling de heap | Sem baseline |
| Qualidade das detecções | Precisão e revocação em datasets rotulados | Sem baseline |
| Reprodutibilidade | Comparação de execuções equivalentes | A validar |
| Recuperação | Testes após falha simulada | Parcial |
| Segurança | Testes negativos de acesso | Parcial |
| Rastreabilidade | Alertas com regra, versão e evidência | Parcial |

Metas numéricas devem ser definidas a partir
de medições reais, registrando hardware, ambiente,
versão, dataset e configuração.
